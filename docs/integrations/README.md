# 外部系统对接资料

本页索引由本项目维护、供外部系统集成使用的版本化资料，包括元数据、机器可读契约和合成验收样例；实际目录按消费端路径约定维护。它不是引擎源码或运行时模块，也不存放外部系统的实现代码。

## 1. 目录索引

| 目录 | 内容 |
| --- | --- |
| [`gateway/`](gateway/README.md) | Gateway 对接说明、参考 Schema 和 MCP 结果展示契约 fixtures；版本导入元数据位于仓库根目录 `gateway/` |

引擎的专题设计、接口和运行说明仍以[文档总览](../README.md)列出的事实源为准。本目录只说明对接资料及其交接要求，不重复维护产品或实现文档。

## 2. 维护规则

- 按外部系统分目录，各目录通过 README 说明文件用途、消费方式和交接边界。
- 配置和契约只维护一份，不保留重复副本或兼容符号链接。
- 机器可读文件仍可能作为构建、测试或外部导入的输入；不能将它们视为仅供阅读的示例。
- 调整目录或文件名时，同步本仓构建脚本、测试、生成器和文档引用，并核对外部消费端的路径约定。移动文件不会自动修改外部部署配置。
- fixtures 仅使用合成或脱敏数据，不保存真实业务归档、有效密钥、令牌或环境专用生产配置。
- 本地契约、构建和模拟测试通过，不等于外部系统已部署或真实联调完成；未验证事项应在对应目录说明中明确记录。

各对接包的具体验证命令与兼容性要求见其 README；通用测试规则见[测试说明](../operations/testing.md)。
