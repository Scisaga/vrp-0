# REST API 说明

## 1. 文档目的与边界

本文负责 REST API 的整体原则、当前资源语义、资源分组、任务状态、错误、大对象和兼容规则。

本文不复制或改写精确路径、HTTP 参数、请求体、响应字段和 Schema；这些内容唯一以机器可读的 [`docs/openapi.yaml`](../openapi.yaml) 为准。MCP Tool 契约见 [MCP 参考](../reference/mcp.md)。

## 2. 接口原则

* API 以当前场景为求解上下文，不要求调用者在每次操作中选择场景。
* 场景写入是创建或更新语义，并可明确声明按导入替换处理；读取和删除都针对当前场景。
* 求解任务既有面向最新任务的便捷操作，也有面向任务历史的列表和按标识操作。
* 业务前置条件由应用门面统一验证，REST 与 MCP 复用相同规则。
* JSON 命名、格式、必填性和枚举值以 OpenAPI 为准，文档说明不得另建一套字段定义。

## 3. 当前场景与当前任务语义

### 3.1 当前场景

系统只维护一个当前场景。不存在当前场景时，严格读取返回资源不存在；可选读取用于控制台初始化，可返回空值。普通写入更新同一当前对象；按明确的导入替换语义写入时清理原场景对应的任务历史。

求解运行期间场景不可替换或删除，以避免输入与正在写回的解不一致。

### 3.2 当前求解任务

任务仓库保存历史列表，并用最新任务指针表示当前任务。创建新任务后它成为当前任务；删除当前任务后，指针更新为剩余历史中的最新项或为空。

面向当前任务的读取、终止、应用和删除是便捷语义；按标识接口用于历史任务。二者操作同一 `SolverJob` 记录。

## 4. 资源分组

| 分组 | 职责 |
| --- | --- |
| 根与节点信息 | 控制台入口、地图运行上下文、配额、MCP 摘要与参考文档 |
| 当前场景 | 读取、可选读取、创建或更新、按导入替换、删除、查询可用 Agent |
| POI | 关键词查询、地址解析、逆地址解析 |
| AMap 矩阵缓存 | 在 AMap 运行模式下获取或更新进程内路由缓存；不直接读写当前场景或任务方案中的矩阵 |
| 求解任务 | 启动、读取最新任务、终止、应用和删除 |
| 任务历史 | 列表筛选、按标识读取、应用或删除 |

精确资源路径及 HTTP 方法只在 OpenAPI 契约中维护。

## 5. 状态与并发规则

任务状态语义见[求解器设计](../design/solver.md)。API 层遵循以下边界：

* 创建任务是异步操作；成功响应表示任务已经接受并持久化，不表示求解完成。
* 调度中和求解中的任务都视为运行中。
* 已有运行中任务时拒绝再次创建任务。
* 只有运行中任务可以终止；运行中任务不能删除。
* 场景替换、场景删除、启动任务和应用结果通过同一协调器串行执行。
* 应用任务结果之前验证它与当前场景的求解对象兼容。
* 按产品约束只应应用已停止任务；当前 REST 应用路径和页面按钮尚未显式限制任务状态，这是实现缺口，不能视为支持运行中回写。

## 6. HTTP 结果语义

* 成功读取或同步更新返回成功结果。
* 请求格式、枚举、时间格式或前置数据不合法返回客户端请求错误。
* 当前场景或任务不存在返回资源不存在。
* 场景变更被运行中任务阻塞、重复启动或其他状态竞争返回冲突。
* 未分类服务端异常返回内部错误。通用错误响应不直接携带完整堆栈，但当前任务异常对象可能包含堆栈信息。

当前 REST 没有应用内用户或角色认证；访问限制由部署入口承担。每个操作声明的响应码和响应体以 OpenAPI 为准。

## 7. 错误契约

错误响应提供请求关联标识、稳定错误码、结构化参数和诊断消息。调用者应：

1. 以稳定错误码判断错误类别。
2. 使用结构化参数生成面向用户的上下文。
3. 把诊断消息用于日志或兜底，不以消息文本做流程分支。
4. 对未知错误码提供通用、安全的本地化提示。

当前 REST 错误类别覆盖资源缺失、参数或 JSON 无效、场景前置条件、场景变更冲突、任务状态、应用不兼容、地图服务不可用或调用失败，以及通用前置条件和内部错误。精确枚举仍以 OpenAPI Schema 为准。

## 8. 大对象与响应边界

* 场景和任务的在途矩阵在文件存储中与主体分离。
* 查询 `SolverJob` 时移除矩阵，避免任务查询携带大对象；启动和终止操作当前没有统一执行该裁剪。
* 任务列表返回摘要并支持筛选；摘要包含可直接展示的当前最佳或最终得分，但不返回完整规划解。正常完成任务的更新时间同时是当前可用的求解完成时间事实，接口不重复返回第二个时间字段。
* 当前场景矩阵通过场景保存/构建流程维护，任务矩阵由任务仓库维护。矩阵资源只访问 AMap 进程内路由缓存，不能用它替代场景或任务矩阵的持久化入口。
* 请求体上限是运行配置，不代表所有接口都应接受接近上限的对象。

## 9. 兼容规则

* 路径、方法、字段、格式、枚举或响应码变化属于 API 契约变化。
* 契约变化按[文档总览的更新规则](../README.md#6-更新规则)同步维护。
* 只改变内部类、文件布局或实现方式且外部契约不变时，不应改写 OpenAPI。
* 新字段不能只出现在代码或示例中；弃用或兼容行为必须在 OpenAPI 中明确表达。

## 10. 非目标

本文不定义新端点、版本协商、批量场景接口或外部系统协议，也不补写 OpenAPI 中不存在的字段。
