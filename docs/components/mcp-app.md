## 3. 信封与安全快照

页面只消费 `_meta.gateway_ui`，继续严格校验固定 view、当前工具名、任务、版本、工程师、`result_summary=null` 和安全模型。无最终结果时 `engine_view=null`；出图失败不改变已就绪模型、任务状态或 Gantt。

SVG Map context 保留 `enabled/provider/locale`，并有 `render_mode=svg_snapshot_v1`、`snapshot`、`error_code`；旧 `browser_key/js_url/renderer_url/renderer_origin` 必须为空，`css_url=null`。`enabled=true` 当且仅当快照存在；Gantt context 沿用原禁用结构，不增加 SVG 字段。

Gateway 下载并严格解码校验原生 2048×1536 图片后，完整下采样到 1536×1152 JPEG 85、4:2:0，仅替换底图，不改变覆盖范围、署名、投影或矢量内容。不新增产物声明、工具入参、信封字段或版本分流；`svg_snapshot_v1` 和 Gantt 不变。Gateway 与支持 1.5× 的 Map HTML 须配套交付，先通过本地工作区验证，不覆写既有 tag/URI。

快照包含 `svg`、固定逻辑 `width=1024/height=768`、`attribution`；当前内嵌底图为 1536×1152（1.5×），解码同时兼容历史 1024×768（1×）及 2048×1536（2×）PNG/JPEG。其余字段包括投影 `{kind:web_mercator,world_size,origin_x,origin_y,center_longitude}` 及元素映射 `{agents,tickets,routes}`。工程师映射含起点与独立回放元素 ID、业务 ID 和像素坐标；工单映射含业务 ID、展示工程师归属、元素 ID 和坐标；显示归属沿用非虚拟 agent.tickets 顺序首次有效引用，剩余工单以 null 中性标记展示（含虚拟/未知归属），不改 engine_view 的业务归属或回放资格；路线映射保留工程师、原数组下标、元素 ID 和返程标记。业务 ID 不直接拼成 SVG ID/选择器。元素引用与安全模型核对，多卡片用实例前缀隔离 ID。

SVG 挂载前解析并逐元素、属性白名单校验；拒绝脚本、事件、foreignObject、DOCTYPE、外部引用及非 PNG/JPEG data 图片。禁止直接信任工具结果后设置 innerHTML。底图必须为内嵌图片，不从浏览器访问 Planly 或图商；纯文本署名固定显示，不随取景或筛选隐藏。

后台和前端使用相同 Web Mercator 公式，将经度绕到最接近 `center_longitude` 的整圈后投影。POI `location` 为经度、纬度；历史 Route.LOC 的 `lat` 为经度、`lon` 为纬度，不二次修正坐标系。真实路线来源、原段位、缺失几何、返程与回放资格沿用安全展示契约。

### 首次结果缺少元数据时的一次补取

从 `1.1.6-alpha-SNAPSHOT` 起，Map/Gantt 共享桥在首次成功工具结果仅缺少 `_meta.gateway_ui` 时，允许通过官方 `App.callServerTool` 补取一次。必须已完成宿主握手、声明 `serverTools` 能力、收到合法的原始 `tool-input`，并确认当前固定展示工具。从 `1.1.7-alpha-SNAPSHOT` 起，Gateway 成功结果的 `structuredContent.display_tool_name` 也可提供已校验的完整原始工具名，页面严格核对其 Map/Gantt 类型与摘要版本；宿主提供 `toolInfo` 时还必须与该名称一致。旧摘要没有该字段时仍可使用合法的宿主工具名；两者均缺失或任一已提供的身份非法、冲突时不补取，不猜测工具名或移除宿主前缀。公共摘要同时核对契约、任务、版本、view、工程师、`ui_available=true` 和 `result_summary=null`，不能用作绘图数据、授权凭证或绕过信封校验。

补取使用同一工具和原始入参，超时 10 秒，返回值仍从 `_meta.gateway_ui` 读取并执行既有 Schema、身份和业务语义校验。每个卡片、每次合法输入最多一次；重复的缺失元数据通知不能重入或形成循环。新输入、取消、销毁或后续完整/错误通知使旧请求失效，晚到结果不能覆盖当前卡片。补取期间显示既有加载状态；能力/身份不足、补取失败或仍缺少元数据时显示既有安全降级信息。

完整初始结果不增加工具请求；业务/认证/权限错误、存在但非法的元数据及身份不匹配不得触发补取。逻辑随引擎两份 HTML 交付，不通过 Skill 配置，不依赖浏览器 REST、轮询、额外聊天消息或新求解任务。Gateway 继续负责工具授权及只读执行，绘图数据位置不变。已有历史卡片若保存的摘要没有工具名、宿主也未提供身份，仍安全降级，需重新调用当前任务展示工具；新页面不能凭空恢复该身份。该路径是否能绕过 Quick 的元数据丢失须真实客户端单独验证，模拟宿主通过不表示 Quick 已修复。

## 4. Map 交互与生命周期

保留工程师本地筛选、点位与路线选择、高亮、图例、适配路线、平移缩放、全屏侧栏、搜索和规划回放。快照固定覆盖全任务并留出周边真实地图，不添加视口工具参数；缩放仅放大已有底图，不新增街道细节、不支持无限地图浏览。筛选不请求后端，工单点击联动既有详情。

工单圆点由页面保持固定屏幕尺寸：含白边的普通直径 22 CSS px、选中直径 26 CSS px，白边 1.5 CSS px，序号居中、常规字号 11 CSS px，较长序号适度缩小但不截断。透明点击区直径 32 CSS px，键盘焦点和选择反馈保留；地图缩放、平移、筛选、resize、全屏与 DPR 变化不放大圆点或数字，工单中心仍与原投影坐标对齐。取景按工单锚点与既有屏幕留边计算，不将随视口补偿后的图形包围盒反复反馈到取景。不改变服务端 SVG 或外层数据契约。

工程师起点与规划回放位置使用同一路线色的圆角方形人形标记，普通外径 22 CSS px、选中 26 CSS px，透明点击区 32 CSS px；图标、白边与姓名不随地图缩放。完整姓名以 12px 浅底标签在选中、悬停或键盘聚焦时显示，长姓名换行，标签限于地图可见区且可由 Escape 关闭。只有原投影坐标完全相同的可见起点才汇总成人形加人数的中性标记，不偏移真实位置、不聚合仅距离接近的点；点击或 Enter/Space 展开有界列表，保留姓名、业务日期及路线色标，支持方向键、首尾、Tab、Escape 和焦点返回，选择沿用已有本地筛选。显示集合、缩放/平移、模式或尺寸变化、页面失焦/隐藏及销毁后关闭列表。规划回放移动同一人形标记，隐藏对应静态起点；回放位置不参与起点汇总，退出后恢复起点及汇总，继续标明为计划位置。浮层不增加卡片高度，不遮挡地图操作，权限失效与卡片销毁后清理，实例互不影响。

- 从图片真实解码像素计算清晰缩放上限，只接受横纵一致的 1×、1.5×、2×，拒绝其他密度或比例；默认一个源像素最多对应 2×2 设备像素。达到边界禁用相应按钮，滚轮/键盘同样受限。
- 所有视口路径限制在底图内，不露出越界灰图。触边提示按手势去重，使用中英文及读屏状态；会话模式的缩放上限和触边提示均明确引导点击“全屏查看”。已经全屏时不再提示进入全屏，触边可引导“显示完整路线”；中英文提示仅保留当前限制和操作引导，不附加范围或细节不增加的解释。提示随模式切换更新，模式/尺寸变化时不重复播报未变化的内容。
- 首次展示与完整取景优先全部路线和点位；极端比例调整有效画布并居中，空余区域使用页面背景，不以裁切路线铺满。取景态 resize 重新适配，手动态保留中心和比例并按边界修正，不重建实例。
- 路线选择按工程师 ID＋原路线下标独立维护，约 12 CSS px 透明命中区；仅沿原折线加粗并增加浅色衬线，不绘制包围整段的矩形黑框，保留工程师配色、箭头和返程虚线。鼠标焦点不显示浏览器默认矩形轮廓；键盘焦点以沿线加粗和衬线呈现，保持可辨识。不改变工程师筛选或回放运行状态、不自动取景，不增加浮层、路段详情或全屏提示。空白/Escape、任务/筛选/点位切换清除；resize/全屏保持，拖动不误触选择，键盘同样可用。
- 动态 SVG 及命中区继续受白名单、数据映射和实例隔离约束。没有新增字段、API、秘密或浏览器网络；深色低 POI 和服务端浏览器不纳入本轮。

回放由原 `buildReplay` 根据已有真实折线及业务时间计算；SVG 视图仅投影、移动回放标记，不推算返程时间或实时位置。默认暂停，退出全屏、隐藏、地图失败、权限失效或销毁时暂停。所有选择、视窗、计时器均按卡片实例隔离；不使用 Cookie/Web Storage/全局任务缓存，不轮询或调用 REST。

地图生成失败时保留独立安全模型与 Gantt 入口，显示固定安全错误码，不以无底图路线图冒充成功。地图重试仅通过已验证的当前地图工具经宿主重新获取，不新增视口参数。获准网页入口由 Gateway/宿主既有能力提供，页面不猜测 URL。认证/权限失效清空内容，取消及新输入使晚到响应失效。

会话画布在所有可用宽度统一保持 3:2，不因窄屏变为正方形，整体随画布与控件内容收缩，不增加空白占位；全屏继续填满剩余高度。Map 工具栏在会话及全屏、中英文下均保持单行，窄屏由工程师下拉框收缩适配，保留完整选项和可访问名称，按钮不重叠或换行，取景提示不越出卡片。工程师姓名与路线色标合并到顶部筛选下拉框，默认显示全部工程师及已知数量，选中后显示姓名及色标；完整姓名、业务日期与选中标记在展开列表内展示，可切回全部。会话和全屏均移除底部人名区、分隔线及占位；原地图告警以按需提示保留。展开列表按宽度使用两列或单列，在宿主可见范围内滚动，浮层不参与卡片高度计算；键盘与鼠标均可选择，取消、外部点击、显示模式变化、隐藏及失效清理均关闭浮层。路线取景图标/提示和底部 Gantt 意图入口保持，无只读说明占位。全屏只是宿主模式，不新增页面或任务。

## 5. Gantt App

Inline Gantt 使用真实业务时间轴、工程师本地筛选和局部滚动，不提供放大或缩小按钮。服务以独立浅蓝工单块展示“短地点 + 服务时长”，不在块内重复工单编号或序号；行程是带端点的蓝色细线，上方汽车图标和时长无底色、边框或阴影，短行程也保留标注，不拉长真实区间。行程/等待的紧凑标注按分钟四舍五入，不足一分钟显示 `<1分`（英文 `<1m`）；完整提示仍保留秒精度。等待使用弱化的灰色斜纹带，空间足够时显示时长。地点优先使用 POI 地址，仅对可可靠识别的门牌街道或设施名称做展示层简化；带单元/楼层或格式不明的地址保留原文，以省略号适配空间。地址缺失时回退已有名称，再缺失则显示本地化未知提示；不修改原数据、不调用地理编码。完整地址、工单编号、阶段起止时间保留在提示和详情中，服务时长只由合法的真实起止时间计算。明确的虚拟工程师从排程行、工程师筛选和全屏工程师列表中隐藏；未知类型保留，原投影、工单归属和业务计数不改写。顶部刻度优先使用整点/规则间隔并保留时间轴真实端点，仅显示时分（非整分钟端点保留秒）；左侧工程师名下同行展示完整业务日期和分钟精度的计划执行范围。范围沿用控制台 Gantt 的优先级：有效工单阶段存在时，通常由班次开始至引擎提供的 `tickets_done_time`；服务早于班次则起点前移，起点未知则取最早服务/阶段开始，完成时间未知则取最后阶段结束。无效范围先回退有效阶段范围，仍不能形成正时长则显示 `-`，不回退整个可用班次；无工单或没有真实有效阶段显示 `-`，不能展示整个班次代替排程。MCP 只使用真实且时序合法的 arrival/start/departure，不沿用控制台对缺失或零时长服务的结束时间估算；班次起止仍在 Gantt 工程师详情中分别展示。范围仅展示已有业务时间，不推算返程，不新增返程条或改变地图回放与时间刻度范围。次日端点标注“次日”（英文 `+1d`），其他日期差异显示完整日期；日期未知时不补写日期，以执行起点日期作为相对日参照。刻度提示及执行范围可访问名称保留完整日期时间，业务时间不做时区转换；左列按实际信息宽度统一适配，窄屏只在时间轴内横向滚动。会话排程高度随可见行数收缩，行多时在有界区域内滚动，单工程师详情紧贴排程，不留固定高度空白；未选择对象时不保留空详情区。Gantt 移除底部“只读结果”说明行，时间轴可访问说明仍标明业务计划时间。

页面不包含任务摘要、地图页签、地图 SDK、browser key、adapter 或网络请求。Fullscreen 在完整时间轴右侧提供工程师/工单侧栏、检索、详情和选择联动；不包含地图或回放，仍填满宿主剩余高度。结果通知将已选工程师明确标为虚拟时清除该工程师的本地焦点及详情，不把其继续保留在隐藏排程中。

Gantt 阶段图例和工程师筛选共用同一行，图例左对齐、筛选右对齐，不保留独立筛选工具栏。窄屏仅允许图例内部换行，筛选仍在同行右侧且保留可访问名称；对象列表入口移到页头操作区。未选择对象的会话或全屏详情区保持空且不占位，不显示选择工程师或工单的说明注释，选择后的详情及 Map 既有提示不变。

Map/Gantt 顶栏均不显示 VRP-0 Logo 或系统名称；Gantt 仍显示当前视图标题，Map 页面操作并入工具栏。两个 App 都跟随宿主中英文、浅深主题、显示模式和尺寸，保持键盘焦点、读屏名称、非纯色状态表达与 `prefers-reduced-motion` 支持。视觉事实源仍是 [`docs/ui/theme.md`](../ui/theme.md)。

两卡片的可用宽度由宿主容器决定。共享 Viewer 的 `ui/notifications/size-changed` 仅上报内容高度，不将 iframe 的 viewport 宽度作为期望宽度回传；否则宿主按像素应用该值后，代理层滚动条占用的宽度可能在连续测量中被重复扣除。初始化、内容变化、窗口缩放及重新挂载均遵循此规则，高度仍按现有内容布局更新。


Map 出图失败不阻断独立 Gantt，Gantt context、业务页面和安全投影不增加 SVG 字段；本轮仅完整回归共享桥、样式及发布清单。
