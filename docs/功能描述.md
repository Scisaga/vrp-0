# 功能描述

## 场景管理-场景列表
- 列表展示历史场景，展示场景的id，poi数量（工程师/工单/仓库），关联求解任务数量，创建时间等
- 支持根据id，时间段查询
- 支持场景的CRUD，有场景新增按钮，点击跳转新增场景界面；点击删除需校验是否存在使用此场景的求解中的任务，没有时允许删；点击列表项跳转场景明细页面，支持修改数据（无进行中任务时）
- 点击跳转场景关联任务的列表，自动筛选该场景id

## 场景管理-场景详情
- 展示场景基本信息
- 场景响应展示 `map_provider`；创建或更新未填写时使用当前运行实例的 `MAP_PROVIDER`，填写与实例不一致时明确提示并拒绝保存。
- 已保存场景的 `map_provider` 与当前运行实例不一致时，Engine Host 提示用户清除当前场景后重新录入或导入；用户确认后才删除场景及关联任务。
- POI信息展示在多sheet的表格中，分别展示工程师/工单/仓库信息，历史工单使用差异色显示。
- 单独sheet展示场景约束配置，约束包含中英文介绍
- 配置页签工具栏只保留页签和当前操作；当前页签内嵌信息图标，页签悬浮、键盘聚焦或点击时显示当前页签说明的提示浮层，避免英文说明改变工具栏行高，并明确提示归属。
- 支持跳转关联求解任务列表

## 地图与路线展示
- 页面先读取 `GET /map_context`，再按当前实例选择 AMap（GCJ-02）或 HERE（WGS84）地图 SDK。
- 地址搜索、地图选点、Marker 拖拽、路线/返仓预览和求解回放均使用同一个已选择图商；图商失败不自动切换到另一家。
- 矩阵模式展示为 `ROUTING`（使用当前图商）或 `MANHATTAN`；旧输入 `AMAP` 仅作兼容并归一为 `ROUTING`。

## 界面语言与 API 错误
- Engine 顶栏提供简体中文（`zh-CN`）和美国英语（`en-US`）切换；默认简体中文，选择仅保存在浏览器 `localStorage`，不会改变 API 请求的 `Accept-Language`，也不会清空当前页面数据或场景草稿。
- Engine 语言覆盖导航、列表、配额、MCP、Host 注入按钮、对话框、通知、系统状态、日期/时长和错误提示。业务枚举以当前语言显示；API 返回的原始状态、JSON 字段、品牌名及用户输入保持原样，未知枚举值也原样显示。
- Engine 与 Scenario 的第一方界面文本必须使用各自语言包的语义化 `t(key, params)`；不得将中文原文作为翻译索引。Host 动态注入的控件保留消息 key，切换语言时原地更新。旧模板允许在明确标记的兼容根内使用 DOM 翻译器，禁止对 `document.body` 或整个组件 Shadow Root 作无差别扫描。
- Scenario UI 使用独立的组件语言包。Host 在 `context.locale` 传入 `zh-CN` 或 `en-US`；缺失或非法值回退 `zh-CN`。Host 切换语言时调用组件 `updateContext()`，组件只更新显示文本，不重新创建场景草稿或结果业务数据。
- `map_context.locale` 仅控制地图 SDK 的语言，与 `context.locale` 的组件显示语言是两个独立输入。Engine Host 会将当前顶栏语言显式写入 `map_context.locale`。HERE 原地替换底图语言图层；遗留 AMap 1.4 为同时保留原生 `darkblue` 主题与语言会重建底层地图 SDK，并立即恢复相同路线和 Marker。若英文瓦片忽略 AMap 深色主题，仅底图层采用深色兼容滤镜，路线和业务 Marker 保持原色，不清空草稿或结果。
- REST 错误响应在保留兼容 `message` 的同时，提供稳定 `error_code` 和仅含非敏感标量的 `error_params`。网页只根据这两个字段本地化错误，绝不直接展示服务端 `message`；缺失、未知错误码和网络错误显示本地化通用错误。

## 求解任务管理-求解任务列表
- 列表展示求解任务信息，支持根据场景id、状态、求解时间段筛选
- 支持手动中止任务
- 点击列表接入求解任务详情

## 求解任务管理-求解任务详情
- 展示求解任务基本信息（状态、时间、得分）
- 跳转查看场景详情
- （求解完成）甘特图展示工单顺序
- 刷新按钮更新状态
- 支持手动中止按钮中止任务

## 求解任务管理-限流管理
- 设置并发求解限制，支持按任务数量限制

## 求解任务管理-队列管理
- 支持查看队列任务信息，支持调整队列中任务顺序、删除任务











## 5. 对求解生命周期做可视化
- 求解前：工程师、工单、仓库信息展示；配置的默认约束清单展示。
- 求解中：求解分数曲线展示
- 求解后：工单分派结果；POI+poyline；求解结果分析（AI）；求解效果/时长优化方案（AI）
